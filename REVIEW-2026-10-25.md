## 3. UI and performance (what a user feels)

1. **First paint takes 20–30 s** (measured; "Still working…" on Today). `/api/status` computes
   `freshness()` on the request thread; `_price_day("us")` alone took 13 s cold (the 45-day
   `recent_counts` query index-only-scans 178k rows with 148k heap fetches, `marketdata/freshness.py:60`).
   The Today page and the header dot both call `/api/status` at once on load (`app.js:6147`, `:7108`); both
   miss the 60 s cache and both recompute. Fix, in order of payoff:
   - refresh the freshness cache in a background thread and always serve the last copy
     (`web/server.py:3043-3050`), with a lock so concurrent misses compute once;
   - give the web process a connection pool: `marketdata/db.py:34-41` is a module singleton shared by
     FastAPI's threadpool, so one slow query stalls every other request (this is why `/api/markets`, a 4 ms
     call, waited 13 s in the browser);
   - have the daily `prices` job store the per-day row counts (a tiny table) so freshness never scans `prices`.
2. **Phone width.** The Strategies page's data table overflows the viewport (scroll width 631 px at
   375 px) so the whole page scrolls sideways; the sidebar fills the screen with no content visible. Wrap
   `.data` tables in an `overflow-x: auto` container and collapse the sidebar into a select at narrow widths.
3. **Earnings badge colour alone encodes beat / miss** (`style.css:1534` `.ev-ic.E.pos/.neg`); add a ✓ / ✗ or
   text in the badge so it reads without colour. Same for `.dotm` market dots and `.fpi-bar` bars.
4. **Keyboard.** `dataTable` rows and sector-leader links (`<a data-s>` without `href`, `app.js:2997`) have no
   keyboard path (18 click handlers on `tr`/`div`/`span`, no `tabindex`/`role`). Screen-builder value inputs
   (`app.js:3878-3879`) have no label.
5. **Chart page rebuilds itself 15 s after opening** when news lands: `api()` calls `route()` whenever a
   cached GET's body changes and `news`/`prices` are in `CACHEABLE` (`app.js:28-36`), losing zoom and a
   drawing in progress. Exclude those keys or let pages opt in.
6. **Job queue.** 100 backtests are queued behind one `backtest` lane whose current item has a 3.9 h ETA —
   several days of backlog, mostly `--const` sweeps. Either raise the lane's workers or prune the sweeps.
7. Copy: "1 analysts revised up" (`marketdata/estimates.py` read line) needs a plural rule.

## 4. Server correctness (committed)

1. **500s on bad input** (confirmed with curl): an unparsable `date` on `/api/patterns`, `/api/stage-analysis`,
   `/api/setups/{strategy}`, `/api/screens/{key}`, `/api/postmarket`; an unknown `market` on
   `/api/sectors` and `/api/sectors/group` (which also runs a 10 s compute synchronously); a non-numeric id on

2. **`_sector_cache` is defined twice** (`web/server.py:948` and `:2020`); the second rebinds the name, so the
   Breadth page's `clear()` wipes the Sectors ranking and the next `/api/sectors` recomputes synchronously.
   Rename one.
3. **Hard-coded markets (CLAUDE.md).** `status.py:30 BENCH_SERIES` (a third market would KeyError
   `/api/status`), `server.py:1937-1943` movers constants, `:3130 _resolve` with `.NS`, `ingest.py:156`
   accepts only `("us","india")`, ~20 endpoints default `market="us"`/`"india"`. Client: `app.js:498 BENCH`,
   `:1914 moneyShort` picks ₹/$ by `market === "india"`, ~20 `.replace(/\.NS$/, "")` sites. Use
   `MARKETS[m].benchmark_symbol`, `mktInfo(m).currency` / `.suffix`.
4. **Queue table read outside `jobs/queue.py`**: `schedules_api` (`server.py:2690-2693`) selects from
   `job_queue` directly. Add a `queue.last_by_schedule()` helper.
5. **GET with side effects and a process leak**: `/api/news/{m}/{s}` spawns `jobs run news` on a GET and
   `_news_jobs` keeps every Popen (`:638-709`). Reap finished ones; make refresh a POST.
6. **Write endpoints without `_require_local`**: screens save/delete, watchlists, notes, todo, drawings,
   `/api/ingest` (runs a full ingest on the request thread). Safe only while bound to 127.0.0.1; apply the

7. **Unbounded scans**: `/api/trade-runs` loads every run's full `trades` JSONB to count one symbol
   (`:711-735`); `/api/symbol-context` loads every candidates table. Fine today (0.3 s), linear in run count.
8. Smaller: `todo_toggle` accepts a negative index (`:2993`); `_strategy_docs` hot-reloads strategy modules

## 5. Backtest accuracy (committed) — worth its own sprint

Ranked by how much they move a result. Each is confirmed in source.

0. **Minervini's power play (S5) can never trade.** `strategies/minervini_spec.py` `build_plans` buys a power
   play at the close through the flag's pivot and stops under the flag's tight low, so its risk is at least
   pivot minus tight low. Its measured move is that same distance, so the projection is at most 1R and the
   2:1 minimum (`MIN_STRUCTURAL_R`) rejects every one (KRNT 2020-06-30 projects 0.56R, IRB.NS 2020-08-19
   0.76R). S5 needs a target from a different structure, such as the run that preceded the flag. That is a
   rule change: a version bump and a changelog entry.

1. **`index_signals.sma_overlay` lags two months, not one** (`backtesting/index_signals.py:30-34`):
   `resample("ME").last()` → `shift(1)` → `ffill` onto daily means a day in month k reads month k-2's
   decision. Shift on the daily series after the reindex. Affects `index_investing` trend overlays.
2. **PEAD overwrites a live position** (`backtesting/pead.py:276-291`): two filings for one symbol on the same
   day (129 such pairs in the DB) spend cash twice and the first position vanishes from equity. Check
   `open_pos` inside the loop.
3. **`rotation.simulate` returns a constant positions series** (`backtesting/rotation.py:110`), so sector /
   RS rotation and `ma_trend` stocks mode report 100 % exposure through risk-off stretches. Append the count
   per day.
4. **Trade-level P&L ignores resizes in the ranking runners** (`baseline.py:546-551`, `rotation.py:69-93`):
   equity is right, but win rate / PF / avg R are wrong for momentum_baseline, quality_momentum, rotation,
   ma_trend.
5. **Point-in-time leaks inside a stage**: yfinance-sourced quarters never set `filed`, so `load()`'s
   `COALESCE(filed, period_end) <= asof` makes them public on period end (`marketdata/financials.py:942-976`,
   `:1294`); `spec.results_blackout` reads filing dates past `asof.end_date()` (`backtesting/spec.py:325-327`);
   `spec.market_filter` passes signals before the benchmark starts because `bool(NaN)` is True (`:351`);
   `portfolio_sim` sizes with the fill day's close of other positions (`_mark`).
6. **`fno_income` marks equity only at exits**, and a missing bhavcopy day at `TIME_EXIT` books the full
   spread width as a loss on an OTM spread (`backtesting/fno_income.py:298-299`, `:345`).
7. **Split repair can misclassify a split as real forever**: a `yf.download` exception becomes `raw=None`
   silently, yet `still_there=TRUE` is written (`marketdata/splits.py:121-142`); the `backtest_signals`
   delete runs once after all chunks, so a kill mid-loop leaves re-scaled prices beside stale signal rows.
8. **The screen study is biased** (`screens/snapshot.py:235`, `:503-506`; `screens/study.py:61-70`):
   today's `min_price` applied to back-adjusted history, month-ends built from today's universe, today's
   group RS stamped on every historical snapshot.
9. **The fingerprint cannot see screen-criterion constants or tuple/bool params** (`strategies/base.py:264-290`);
   verified by changing `SMA200_FALLING_PCT` and `cup_depth` with no spec_id change. Include the
   `screen_gates` criteria constants and hashed tuple/bool fields.
10. **Survivorship**: every runner draws from today's universe list (documented in run notes, still unfixed).
11. Smaller: RSI on a flat series is 100 (`core/indicators.py:34`); `backtest_symbol` and `simulate`
    disagree on entry-bar stop handling; `--refresh-history` downloads inside a stage, bypassing
    `cache.offline()` and the boundary.

## 6. Jobs and data layer

1. **`PGPASSWORD` is written into the launchd plist** and printed by `--launchd`
   (`jobs/worker.py:274` copies every `PG*` env var). Load `.env` in the worker instead.
2. **Downloads outside `marketdata/`** (CLAUDE.md): `fundamentals/quality.py:399` (`yf.Ticker`) runs as the
   screening-layer `quality` job; `analytics/breadth.py:134` and `:225` fetch from Yahoo. Move the fetches
   behind `marketdata/` functions.
3. **A verify run that produces no signals is still consumed** (`jobs/registry.py:564-565` records
   `out=None`), spending the once-per-version slot on nothing.
4. **Non-atomic delete-then-insert on an autocommit connection**: `financials._store` (`:1067-1085`),
   `index_data.save(replace=True)`, `derivatives.ingest` (a partial day is never refetched),
   `group_history.ensure`; `quality.fetch` stamps `fetched_at` on exception. Wrap each in a transaction.
5. **Silent `except Exception: pass/continue`** with no log in `backtest.py` (~373, ~380: a strategy bug reads
   as "no signal"), `strategies/earnings_gaps.py:458` (a DB error caches `{}` for the process),
   `providers/yfinance_provider.py:87,97,104`, `financials.py:581,590,922,1018`, `subindustries.py`,
   `universe.py:309`. Log at warning level at minimum.
6. Process-wide caches not keyed by constants or asof (`rs_leaders._recovery`, `earnings_gaps._quarters`,
   `stage_analysis._mkt_stage`, `spec._RANK_ASOF`); `pipeline.apply_live_variant` patches constants for the
   rest of the process, so `strategies` then `backtest` in one `jobs run` can backtest the live variant.
